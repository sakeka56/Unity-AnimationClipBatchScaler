# 1.0.0 发布验证

验证日期：2026-10-28。Unity：6000.3.22f1。

## 安装包

`UnityAnimationTools-1.0.0.unitypackage` 使用 Unity AssetDatabase.ExportPackage 导出，包含四个批量缩放器脚本、四个分段编辑器脚本及其文件夹和 meta。不包含发布辅助脚本、测试、演示动画或第三方模型。

在本仓库 Build 下创建隔离工程进行编译及导出；另建无工具源码的空工程，通过 `-importPackage` 导入安装包。两个 Unity 进程均以返回码 0 退出；导入工程生成了 `Assembly-CSharp-Editor.dll`，包含两套工具的八个脚本。未关闭或重启用户正在使用的 Unity 工程。
